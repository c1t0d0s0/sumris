## 🎮 ゲーム概要

**SUMRIS (サムリス)** は、落ち物パズルの緊張感と暗算の爽快感を融合させた新感覚の数字パズルゲームです。

上からゆっくり落ちてくる **1〜9** の数字ブロックを左右に動かして積み上げます。縦または横に連続して並んだブロックの合計が **「10の倍数（10, 20, 30... 最大90）」** になると、ネオンパーティクルの爆発エフェクトとともにブロックが消去！

残ったブロックが重力で落下し、さらなる連鎖（コンボ）を巻き起こします。画面内のすべてのブロックを消去する **完全クリア（PERFECT CLEAR）** を目指しましょう！

---

## ✨ 主な特徴

- **10の倍数で消える足し算ルール**:
  - 縦または横に連続したブロックの合計が「10, 20, 30...」になると消去。
  - 3個以上のブロックを同時に足しても消去可能。
- **多彩なスコアボーナス & 連鎖システム**:
  - **ビッグナンバーボーナス**: 大きな合計（20や90など）や多くのブロックをまとめて消すほど高得点。
  - **交差消し（CROSS CLEAR!）**: 縦と横の足し算が同時に成立するとスコアが **3倍** に跳ね上がります！
  - **連鎖コンボ（COMBO CHAIN!）**: 落下による連鎖が発生するたびにコンボ倍率が上昇。
  - **完全クリアボーナス**: 画面内のブロックをすべて消し去ると、獲得スコアが **2倍** になります！
- **3段階の難易度選択**:
  - **EASY (初級)**: 落下速度 1,200ms | 初期ブロック 5個 | スコア倍率 1.0倍（初心者向け・じっくり計算）
  - **NORMAL (中級)**: 落下速度 850ms | 初期ブロック 7個 | スコア倍率 1.5倍（標準バランス）
  - **HARD (上級)**: 落下速度 500ms | 初期ブロック 12個 | スコア倍率 2.0倍（高速落下＆スコア2倍）
  - 選択した難易度はブラウザの `localStorage` に自動保存されます。
- **ゲーム内チュートリアル（あそびかた画面）**:
  - 基本ルール、消し方、ボーナス、操作方法を4ステップで解説するビジュアルガイドを搭載（`❓` ボタンからいつでも確認可能）。
- **日本語・英語の完全多言語対応 (i18n)**:
  - ブラウザの言語設定（`navigator.languages`）を自動検出し、日本語環境では日本語、それ以外では英語を自動表示。
  - 画面上部の「EN / JA」ボタンでいつでもワンタップ切り替え可能。
- **Web Audio API によるプロシージャルサウンド**:
  - 外部音声ファイルを一切使わず、ブラウザ内蔵シンセサイザーで効果音（移動・落下・消去・連鎖・クリア・ゲームオーバー）をリアルタイム生成。
- **PC & スマートフォンのマルチデバイス対応**:
  - スマホ: 画面下のオンスクリーンボタン（⇦ ⇩ ⇨）および盤面のスワイプ操作。
  - PC: キーボード（矢印キー、WASD）での軽快な操作。
- **ゼロ依存性**:
  - フレームワークや外部ライブラリなし。純粋な Vanilla JavaScript、HTML5 Canvas、CSS3 のみで構成。

## 🚀 ローカルでの動かし方

ビルドツールや Node.js などの依存関係は不要です。ブラウザさえあればすぐに動かせます。

### 1. リポジトリのクローン
```bash
git clone git@github.com:c1t0d0s0/sumris.git
cd sumris
```

### 2. ローカルサーバーの起動 (推奨)
Web Audio API や Canvas 描画の仕様上、ローカル HTTP サーバー経由での実行を推奨します:
```bash
# Python 3 を使用する場合:
python3 -m http.server 8000
```
ブラウザで `http://localhost:8000` を開きます。

※ または、`index.html` を直接ダブルクリックしてブラウザで開くだけでもプレイ可能です。

### (任意) Google アナリティクス等の設定
アクセス解析を行いたい場合は、プロジェクトルートに `config.js` を作成します:
```javascript
const GTM_ID = 'G-XXXXXXXXXX';
```
*(※ `config.js` は `.gitignore` により Git 管理から除外されています)*

## 🚢 GitHub Pages へのデプロイ

リポジトリには [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) が用意されており、タグプッシュ時に **GitHub Pages** へ自動デプロイされます。

### タグによる自動デプロイ手順

`v` から始まるバージョンタグ（例: `v1.0.0`）を push すると、自動的にビルド＆デプロイが実行されます:

```bash
git tag v1.0.0
git push origin v1.0.0
```

> **リポジトリ設定の事前確認**:
> GitHub リポジトリの **Settings > Pages > Build and deployment > Source** を **`GitHub Actions`** に設定してください。
> Google アナリティクス ID を使用する場合は、リポジトリの Variables (`vars.GTM_ID`) または Secrets (`secrets.GTM_ID`) に `GTM_ID` を登録すると自動で反映されます。
